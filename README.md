## 📖 Descripción

**The Grid** es un videojuego de acción inspirado en las carreras de motos de luz de la película **TRON (1982)**.

El jugador controla una motocicleta futurista utilizando un **control físico basado en Arduino**. Mientras se desplaza, la motocicleta deja un rastro de luz permanente que funciona como obstáculo para todos los participantes.

El objetivo es sobrevivir el mayor tiempo posible haciendo que los rivales choquen contra los rastros de luz o contra los límites del escenario.

El proyecto está siendo desarrollado como trabajo para la **Feria de Ciencias** y busca integrar **programación de videojuegos**, **electrónica** y **diseño interactivo**.
